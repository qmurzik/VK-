# Чек-лист проверки на устройстве

Перед началом: удалите оригинальный VK (подпись другая, поверх не ставится), установите `vkmod-signed.apk`,
войдите в аккаунт. Мод запускается вместе с VK; настройки — иконка **«VK Mod»** в лаунчере или долгое
нажатие на вкладку профиля в нижней панели VK.

Если функция не сработала: «Настройки мода → Лог работы мода». Строки `feature '…' disabled after error`
значат, что функция отключилась из-за ошибки (приложение при этом продолжает работать); строки `blocked[…]` /
`filtered …` подтверждают, что сетевые правила срабатывают.

## Базовая работоспособность (без неё остальное не проверять)
- [ ] VK запускается, лента грузится, вход в аккаунт выполняется
- [ ] Сообщения отправляются и приходят, звонок проходит, музыка и видео играют
- [ ] Push-уведомления приходят (см. README → «Подпись и push»; при сбое — это известное ограничение)
- [ ] В логе мода есть `VK Mod 1.0.0 attached` и `OkHttp interceptor ready`

## Внешний вид
- [ ] **1 Движок тем**: включить, выбрать пресет «Dracula» → цвета ленты, шапки, нижней панели изменились (если нет — открыть другой экран)
- [ ] **2 AMOLED**: в тёмной теме VK фон, шапка и панели чисто чёрные
- [ ] **3 Material You** (Android 12+): акцент и фоны берутся из обоев; смена обоев меняет цвета после перезапуска
- [ ] **4 Пресеты**: пролистать все 19; светлая и тёмная темы VK получают свои цвета
- [ ] **5 Редактор**: поменять «Акцент», «Фон страниц» → превью меняется сразу, в VK цвета меняются на новых экранах
- [ ] **6 Импорт/экспорт**: экспорт в файл, «Сбросить мои цвета», импорт файла → цвета вернулись
- [ ] **7 Шрифт**: «С засечками» / «Моноширинный» → тексты на экранах из XML сменили шрифт; «Свой TTF» → выбрать файл
- [ ] **8 Масштаб текста**: 130 → шрифты крупнее на вновь открытых экранах
- [ ] **10 Компактный режим**: 85 → интерфейс мельче; 115 → крупнее
- [ ] **11 Прозрачность панелей**: 60 → шапка/нижняя панель полупрозрачны
- [ ] **12 Форма аватарок**: «Квадрат» / «Скруглённый квадрат» (экспериментально)
- [ ] **13 Фон чата / 14 Пузыри**: слоты «Фон чата», «Исходящие», «Входящие» в редакторе меняют цвета переписки
- [ ] **15 Иконка**: выбрать другую иконку → лаунчер её показывает
- [ ] **16 Анимации**: 0 → анимации отключены; 200 → медленнее
- [ ] **17 Вкладки**: `clips` в «Скрыть вкладки» → вкладки «Клипы» нет; «Скрыть подписи» → только иконки
- [ ] **18 Стартовая вкладка**: «Сообщения» → после запуска открывается она
- [ ] **19 Бейджи**: красные счётчики на вкладках скрыты
