# VK Enhancer

LSPosed-модуль для приложения **ВКонтакте** (`com.vkontakte.android`): скрывает рекламу,
повышает приватность и позволяет полностью перекрасить интерфейс — темы, акценты, AMOLED, шрифты.

Модуль построен на современном **libxposed API 102** (LSPosed 2.x) и **не привязан к конкретной
версии ВК**: ни один хук не опирается на имена обфусцированных классов. Вместо этого используются
устойчивые признаки — контракт серверного API, строковые константы в коде и методы фреймворка
Android. После обновления ВК модуль продолжает работать; при необходимости он один раз
пересканирует новый APK через DexKit и закэширует найденные сигнатуры.

## Возможности

### Реклама
- Рекламные посты в ленте (`ads_*`, `marked_as_ads`, `ad_data`)
- Промо-блоки, кнопки продвижения, карусели Ozon/Юла/маркета
- Реклама в историях и пре-роллы в видео
- Промо-беседы в списке диалогов
- Блокировка рекламных серверов (myTarget, Yandex Ads, AppLovin, Unity, Vungle, Bigo и др.)

### Лента
- Рекомендации («вам может быть интересно», друзья, группы, авторы)
- Клипы, игры и мини-приложения, музыкальные и видео-блоки
- Дзен, дайджесты, опросы и баннеры
- Истории (скрыть строку или отключить полностью)
- Скрытие репостов
- Пользовательские фильтры: по словам и по произвольным типам постов

### Приватность
- Не отправлять отметку «прочитано»
- Скрыть индикатор «печатает…»
- Невидимый онлайн
- Просмотр историй инкогнито
- Блокировка аналитики и крашлитики (myTracker, AppMetrica, Crashlytics, `stats.*`, `adsint.*`)
- Разрешить скриншоты защищённых экранов
- Произвольные списки блокируемых методов API и хостов

### Интерфейс
- Скрытие вкладок нижнего меню (клипы, музыка, сервисы, видео и т.д.)
- Запрет гашения экрана внутри ВК
- Скрытие элементов по имени ресурса-id

### Оформление
- 15 готовых тем (AMOLED, Классика 2016, Telegram, Nord, Dracula, Мята, Сакура, Океан и др.)
- Тонкая настройка цветов по семантическим слотам (акцент, фон, карточки, шапка, панель,
  пузыри сообщений, текст, иконки, разделители, поля ввода)
- Отдельные палитры для светлой и тёмной темы
- AMOLED-режим (чистый чёрный)
- Покраска системных панелей в цвет шапки

### Шрифты
- Выбор семейства (системный, с засечками, моноширинный, свой `.ttf`)
- Масштаб текста 50–200%

## Как это работает (архитектура)

| Функция | Точка хука | Почему независимо от версии |
|---|---|---|
| Фильтр ленты/историй/видео | перехват тела ответа OkHttp | фильтрация по `type`/`marked_as_ads` — это контракт API, а не код приложения |
| Блокировка запросов | перехват OkHttp `Interceptor`/`Chain` | опора на форму интерфейса OkHttp, а не на символы ВК |
| Темы и цвета | `Resources.Theme.resolveAttribute` (Android) | имя атрибута (`vk_ui_*`, `vk_legacy_*`) → семантический слот |
| Скрытие элементов | имена ресурсов-`id` | идентификаторы ресурсов стабильны между сборками |
| Шрифты | `Resources.getDisplayMetrics`, `Typeface` | методы фреймворка Android |

Поиск обфусцированных классов (когда нужен) выполняется
[DexKit](https://github.com/LuckyPray/DexKit) по строковым признакам, результат кэшируется до
следующего обновления ВК.

## Сборка

Требуется JDK 17+ и Android SDK c платформой **android-37** (Android 17) и build-tools 37.

```bash
./gradlew :app:assembleDebug      # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest  # юнит-тесты фильтров и классификатора цветов
```

Готовые сборки также публикуются во вкладке **Releases** (собираются GitHub Actions).

## Установка

1. Установите [LSPosed](https://github.com/JingMatrix/LSPosed) (Zygisk) — требуется root/KernelSU/Magisk.
2. Установите APK модуля.
3. В LSPosed включите модуль **VK Enhancer** и отметьте в области действия приложение
   **ВКонтакте**.
4. Перезапустите ВКонтакте.
5. Откройте «VK Enhancer» (ярлык или из списка модулей LSPosed) и настройте функции.

> Настройки передаются в процесс ВК через удалённые настройки LSPosed и применяются «на лету».
> Если в окне настроек показан предупреждающий баннер — модуль ещё не активирован в LSPosed.

## Дисклеймер

Проект создан в образовательных целях для персональной кастомизации официального клиента на
собственном устройстве. ВКонтакте — торговая марка её правообладателя; модуль не аффилирован с ним
и не распространяет чужой код.
