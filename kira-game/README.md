# KIRA ♥ — виртуальная жизнь вдвоём

3D-игра для ПК в духе MiSide, только про любовь. Ты попадаешь внутрь приложения
«QVK: Kira» и неделю живёшь в квартире Киры: готовишь с ней завтраки, играешь в
приставку, прячешься, танцуешь, смотришь на звёзды — и узнаёшь, почему она
позвала тебя именно сейчас.

**Длительность:** ~1.5–2 часа (пролог + 7 дней + одна из трёх концовок).

## Как играть

### Вариант 1 — готовый .exe (Windows)
Сборка собирается автоматически GitHub Actions при каждом изменении игры:

* **Releases → `kira-latest`** → скачай `KIRA-1.0.0-portable.exe` и запусти
  (установка не нужна). Windows SmartScreen может спросить подтверждение —
  «Подробнее → Выполнить в любом случае» (файл не подписан).
* или **Actions → KIRA game (Windows build) → артефакт `KIRA-windows`**.

### Вариант 2 — в браузере, без сборки
Открой `kira-game/game/index.html` в Chrome / Edge / Firefox (двойным кликом).
Всё нужное уже лежит в папке `game/`.

### Вариант 3 — собрать самому
```bash
cd kira-game
npm install
npm start          # запустить в окне Electron
npm run dist:win   # собрать dist/KIRA-1.0.0-portable.exe
```

## Управление
| Клавиша | Действие |
|---|---|
| WASD / стрелки | ходить, Shift — бег |
| Мышь | осматриваться (клик по экрану захватывает мышь) |
| E / ЛКМ | взаимодействовать, говорить с Кирой |
| Пробел / Enter / клик | следующая реплика |
| 1–4 | выбор ответа |
| Esc | пауза, F11 — полный экран (в .exe) |

## Что внутри
* **Кира в 3D** — модель собрана процедурно: toon-шейдинг с контуром, рисованное
  анимешное лицо с 18 эмоциями (моргает, говорит, подмигивает, глаза-сердечки),
  чёрные волосы с фиолетовыми кончиками, заколки-крестики, чокер, топ «QVK»,
  куртка с фиолетовыми полосами, ремешок на бедре. Ходит по квартире, садится,
  танцует, обнимает, смотрит на тебя. В диалогах — портрет с оригинального арта.
* **Квартира**: гостиная, кухня, спальня, ванная, прихожая, балкон с видом на
  город; утро/день/вечер/ночь, гирлянды, «сбои» мира.
* **Мини-игры**: готовка (2 рецепта), Пиксель Понг, крестики-нолики (Кира
  жульничает), мемори, рисование портрета, раннер «Star Dash», ритм-танец,
  созвездия, починка секторов, прятки, уборка, фотосессия (фото попадают в
  «Альбом» в меню и в финальные титры).
* **Отношения**: шкала привязанности, выборы в диалогах, темы для разговоров,
  три концовки («Вместе» — истинная, «Навсегда здесь», «Один байт»).
* Процедурная музыка и «голос» Киры, автосохранение в начале каждой сцены
  («Продолжить» в меню), настройки громкости/скорости текста/мыши/графики.
