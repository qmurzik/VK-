# QVK — рекламный ролик для TikTok

`qvk_promo.mp4`: 1080×1920, 60 FPS, H.264 High + AAC 48 кГц, 27 с, без водяных знаков.

## Монтажный план (120 BPM, такт = 2 с)

| Время | Сцена | Текст |
|---|---|---|
| 0–2 с | Чёрный экран, цифровые помехи, расшифровка текста, «выключение» CRT, пауза | «Твой ВК может выглядеть иначе.» |
| 2–3,5 с | Удар баса, логотип QVK со свечением и ударной волной | — |
| 3,5–8 с | Смартфон влетает в 3D, медленный разворот, затем полный оборот с логотипом на задней панели | «QVK», «Твой ВКонтакте. Твои правила.», «На базе VK 8.100 · Android» |
| 8–10 с | Дашборд модуля: 10 разделов, счётчики включённых функций | «90+ функций» |
| 10–12 с | Смена готовых тем на каждый удар: AMOLED → Telegram → Мята → Сакура | «15 готовых тем» |
| 12–14 с | Пипетка ARGB перекрашивает исходящие сообщения | «Цвета чатов» |
| 14–16 с | Рекламный пост и блок рекомендаций исчезают из ленты | «Без рекламы» |
| 16–18 с | Переключатели приватности | «Приватность» |
| 18–20 с | Смена семейства шрифта и масштаба текста | «Шрифты» |
| 20–22 с | Смартфон отдаляется и рассыпается на частицы | — |
| 22–27 с | Логотип, финальный слоган, призыв | «QVK — больше, чем просто ВК.», «Присоединяйся к QVK», «t.me/qvk_chat» |

Все функции, названия разделов, тексты переключателей и палитры тем взяты из исходного кода
(`Sections.kt`, `Features.kt`, `SettingsFragment.kt`, `ThemePalette.kt`, `HomeActivity.kt`).
Экраны приложения воссозданы по этому коду, потому что скриншотов и записей экрана в репозитории нет.
Чтобы заменить их настоящими записями, положите видео в `promo/` и подставьте `<video>` вместо
соответствующего `.scr`-блока в `index.html`.

## Музыка

Оригинальный трек в стиле phonk (808, ковбелл, хлопки, хай-хэты, райзеры, импакты), синтезированный
с нуля в `audio.py`: без семплов и сторонних лицензий, поэтому его можно свободно использовать.
Громкость около −13 LUFS, true peak −1 dBFS.

## Пересборка

```bash
./promo/build.sh       # нужны Node + Playwright (Chromium), ffmpeg, Python 3 + numpy
```

`index.html?t=12.5` открывает любой кадр в браузере для проверки.
