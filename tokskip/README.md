# TokSkip

Аналог SponsorBlock для TikTok: находит рекламные интеграции **внутри роликов** и пропускает их.
Работает полностью на телефоне — без сети (в манифесте нет `INTERNET`), без сбора данных, без
действий с аккаунтом и без скачивания видео.

## Модули

| Модуль | Что внутри |
|---|---|
| `:core` | Детектор рекламы (`AdDetector` + расширяемые `AdSignal`), парсер субтитров WebVTT/SRT, Room-база сегментов, экспорт/импорт JSON, настройки, лог |
| `:accessibility` | Режим без root: `TokSkipAccessibilityService` (только пакеты TikTok), чтение экрана, перемотка, плавающие кнопки разметки, «Дамп UI» |
| `:xposed` | Режим с root: модуль LSPosed (libxposed API 102), хуки ленты / субтитров / плеера через DexKit |
| `:app` | Compose-интерфейс: онбординг, настройки, база, статистика, логи, дамп; ContentProvider для модуля |

## Сборка

```bash
cd tokskip
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk
./gradlew test                   # юнит-тесты детектора, парсера, кодека, часов воспроизведения
```

Нужны JDK 17+ и Android SDK с `platforms;android-37.0` и `build-tools;37.0.0`
(libxposed API 102 компилируется против SDK 37; `targetSdk` = 35, `minSdk` = 26).
На GitHub APK собирает workflow `TokSkip` (артефакт `tokskip-debug`).

## Как пользоваться

1. Установите APK, пройдите онбординг и выберите режим.
2. **Без root:** включите службу доступности «TokSkip — пропуск рекламы».
   **Root:** включите модуль в LSPosed (область — TikTok), перезапустите TikTok. Службу доступности
   стоит включить и здесь — она даёт плавающие кнопки разметки и «Дамп UI».
3. Откройте TikTok. Ролики с найденной рекламой перематываются автоматически.

### Ручная разметка
Главная → «Плавающие кнопки поверх TikTok». На ролике нажмите «▶ Начало рекламы», затем
«■ Конец рекламы» — сегмент сохраняется в базу (источник «вручную») и пропускается при следующих
просмотрах. Сегменты также можно ввести вручную на экране «База» (id ролика или ссылка + `0:12-0:27`).
Разметкой можно делиться: «База → Экспорт / Импорт» (JSON; при импорте ручная разметка важнее
автоматической, иначе побеждает более новая запись).

### Как ролик опознаётся
- Root: по `aweme_id` из модели ленты.
- Без root id ролика на экране не виден, поэтому ключ — хэш начала видимого описания
  (`ui:…`, см. `VideoKeys`). Модуль LSPosed вычисляет такой же ключ, так что ручная разметка,
  сделанная в одном режиме, работает и в другом.

## Детектор

Вход — `VideoMeta` (описание, текст на экране, субтитры с таймкодами, длительность).
Выход — `DetectionResult`: сегменты `[startMs, endMs)` с уверенностью 0..1 и флаг «содержит рекламу».

Сигналы (`core/.../detect/Signals.kt`):
- `DisclosureSignal` — «Реклама», `erid`, ИНН, `#реклама`, `#ad`, `sponsored`, «платное партнёрство»
  (с исключением «не реклама»);
- `TriggerPhraseSignal` — промокод, скидка по ссылке, ссылка в профиле/шапке/описании, «спасибо …
  за поддержку», спонсор, «переходи», скачай приложение, первый заказ, кэшбэк, англ. аналоги;
- `ListSignal` — бренды и свои фразы из настроек (русские слова — с любым окончанием);
- `ContextSignal` — слабая «рекламная» лексика, продлевает сегмент;
- `ReturnToTopicSignal` — «вернёмся», «а теперь», «итак», «anyway» — завершает сегмент.

Сегмент: начало — первая фраза-триггер минус 1 с; конец — возврат к теме, иначе последняя
рекламная строка плюс 1 с. Строки-триггеры дальше 15 с друг от друга — разные интеграции.
Уверенность — noisy-OR весов строк, усиливается маркировкой в описании. Если субтитров нет, а маркер
есть только в описании — `hasAd = true` без сегментов («реклама без таймкодов»).
Новый сигнал — реализовать `AdSignal` и передать в `AdDetector(extraSignals = …)`.

## Ограничения (честно)

- APK TikTok к задаче приложен не был, поэтому классы и id из `RESEARCH.md` — гипотеза по открытым
  данным; модуль ищет их по признакам и при неудаче отключает функцию, не роняя TikTok.
  Инструменты проверки на конкретной версии: `tools/research.sh`, «Дамп UI», подробный лог.
- Без root перемотка возможна, только если TikTok показывает полосу прогресса (длинные ролики).
  Иначе выполняется резервное действие (ничего / уведомление / перелистывание), а позиция
  оценивается по времени с появления ролика (паузы её сбивают).
- Без root субтитры читаются, только если TikTok выводит их текстом в дереве доступности;
  найденные по ним сегменты сохраняются и срабатывают при повторном просмотре.
- Распознавание речи/OCR не подключены: ML Kit не распознаёт кириллицу, а захват звука требует
  MediaProjection с постоянным уведомлением. Детектор устроен так, что такой источник
  добавляется как ещё одни `captions` в `VideoMeta`.
