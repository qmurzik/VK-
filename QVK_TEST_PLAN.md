# QVK 3.0 — план ручного тестирования

Сборка: `QVK-8.100-qvk-3.0.0-alpha1.apk` (versionCode 23800). Перед тестом: установленный **QVK 2.6.18**
с выполненным входом, 1–2 аккаунта, музыка в медиатеке, несколько голосовых в переписках.
Для каждого пункта: ✅ / ❌ + Android-версия + модель + при ❌ — шаги, скриншот и `adb logcat` (или
«Настройки QVK → Диагностика → Журнал ошибок»: компоненты QVK 3.0 начинаются с `qvk3.`).

Матрица устройств (минимум): Android 9 (API 28), Android 12, Android 14; одно устройство без Google
Play services (с microG и без); один слабый (≤3 ГБ ОЗУ).

## A. Установка и сохранность данных
1. Установить 3.0 поверх 2.6.18 (`adb install -r` или файловый менеджер) — установка без удаления. ✅ если аккаунт, переписки, медиа, музыка (кэш ВК), темы и настройки QVK на месте.
2. Повторный запуск, переключение аккаунтов — без вылетов.
3. «Настройки QVK → О приложении → О QVK 3.0» показывает «Обновлено с: 8.100-qvk-2.6.18».
4. Донатерские функции и значки: доступность и разрешения не изменились (сравнить с 2.6.18).
5. Долгое нажатие на иконку приложения → ярлыки «Настройки QVK» и «QVK Music» открываются.

## B. Центр настроек
1. Боковое меню / штатное меню → «Настройки QVK» открывает новый центр.
2. Поиск: «нечит», «pin», «стикеры telegram», «музыка» — релевантные результаты, переключатели работают.
3. Открыть все 15 разделов; в каждом открыть 2–3 экрана/действия (в т.ч. «Быстрые ответы», «Темы», «PIN», «Режим доставки») — открывается соответствующий экран QVK 2.x, «Назад» возвращает.
4. Включить/выключить переключатель → отражается в классическом экране QVK; «↶» отменяет.
5. Долгое нажатие → «Избранные настройки» на главной; «Недавно изменённые» обновляются.
6. «Сбросить раздел» (например «Конфиденциальность») — переключатели раздела вернулись, PIN не тронут, остальные разделы без изменений.
7. «Открывать классические настройки по умолчанию» — меню открывает старый экран; выключить — снова центр.
8. Поворот экрана в разделе и в поиске — состояние сохраняется. Шрифт 200% — текст не обрезается критично. TalkBack — заголовки, состояния переключателей озвучиваются.
9. Системный жест «Назад» (жестовая навигация) — закрывает поиск → раздел → центр, без открытия бокового меню.

## C. Оформление
1. «Темы и персонализация → Стили QVK 3.0» — каждый из 8 стилей: предпросмотр → «Применить». ✅ если меняются лента, сообщения, профиль, нижняя панель; текст читаем.
2. iOS / Modern / Compact — меняются формы и плотность (iOS-компоненты, Material, компактные диалоги).
3. Glass/Neon на слабом устройстве — размытие не включается.
4. «Конструктор» — менять цвета/радиус/шрифт: предпросмотр меняется сразу; «Применить» — интерфейс ВК меняется так же.
5. «Сбросить всё оформление» — тема и стили сброшены, другие настройки и данные целы; затем «↶ / Отменить изменение оформления» в стиле — прежний вид вернулся.
6. Тёмная тема системы + каждый стиль: мерцаний/неправильной перекраски нет (сравнить 2.6.18).

## D. Сценарии
1. Применить «Фокус» — список изменений показан; истории/клипы/рекомендации скрыты. «Вернуть как было» — всё вернулось.
2. «Ночь» → AMOLED; «Музыка» → QVK Music открывается на «Моя музыка», плеер CoverFlow.
3. «Сохранить текущие настройки как сценарий» → изменить пару настроек → применить свой сценарий → значения восстановлены. Удалить свой сценарий.
4. Уведомления не изменяются ни одним встроенным сценарием.

## E. QVK Music
1. Нижняя панель / боковое меню / стартовая страница «Музыка» → открывается QVK Music (не раздел ВК). То же после переключения аккаунта и после возврата из фона. Многократное быстрое нажатие — одно окно.
2. «Моя музыка» на 1000+ треков: прокрутка без зависаний, подгрузка по мере прокрутки.
3. Воспроизведение: play/pause, след./пред., перемотка, перемешивание, повтор 1/все, скорость, A–B, таймер сна (15 мин и «после трека»).
4. Свернуть приложение, заблокировать экран 10+ минут — музыка играет; уведомление и экран блокировки управляют.
5. Bluetooth-гарнитура/наушники: кнопки play/pause/next; отключение наушников → пауза.
6. Входящий звонок → пауза, после звонка — продолжение. Голосовое ВК в чате → музыка ставится на паузу.
7. Открыть штатный плеер ВК (трек из ленты/вложения) во время игры QVK Music → QVK Music на паузе (аудиофокус); одновременной игры нет.
8. Gapless: альбом без пауз между треками; кроссфейд 4 с — плавный переход.
9. Убить процесс (`adb shell am kill ru.qmods.qvk`) → открыть QVK Music: очередь и позиция восстановлены.
10. Режим полёта: «Моя музыка» открывается из сохранённой копии; скачанные треки играют; поиск находит скачанные.
11. Плейлисты ВК → «Скачать доступные треки»: окно покупки подписки **не** появляется; прогресс в уведомлении; отмена/продолжение; файлы в «Музыка/QVK» с названием, исполнителем, обложкой.
12. «Файлы на устройстве» → импорт через системный выбор файлов; «Найти музыку, ранее сохранённую QVK» — старые экспорты видны, не перемещены.
13. Текст песни: трек с официальным текстом ВК → источник «ВК», синхронная подсветка; трек без текста при включённом LRCLIB → текст только при совпадении; ручная прокрутка останавливает автопрокрутку на 4 с; долгое нажатие копирует.
14. Плеер: все 5 макетов, размер/форма обложки, полоса прогресса — меняется без остановки музыки.
15. CoverFlow: инерция, доводка, порядок наложения, отсутствие «выскакивания» по краям, подписи читаемы в светлой и тёмной теме, поворот экрана сохраняет выбранный альбом; касание трека — начинается воспроизведение.
16. Звук: эквалайзер/бас — работают или показано «недоступно на этом устройстве».
17. «Настройки QVK Music → Диагностика → QVK Music вместо раздела «Музыка»» выключить → открывается классический раздел ВК.

## F. Сообщения
1. Голосовое (свежее и старое, >1 недели): долгое нажатие → «Скачать голосовое» → файл в «Загрузки/<папка QVK>» (или выбранной папке) воспроизводится; для истёкшей ссылки без локальной копии — понятное сообщение; сообщение в чате не изменилось.
2. Классический плеер ВК → «Текст песни» — если у трека есть текст ВК, источник «ВК».
3. Удаление диалога (личный и беседа) — запомнить, появляется ли многоточие вместо имени (баг №9, не исправлен — нужен воспроизводимый сценарий).

## G. Обновления
1. «Обновления QVK» — проверка без зависания; при отсутствии источников — понятное сообщение.
2. Тестовый сервер: `update_manifest.py make` для сборки с versionCode 23801 → «Серверы обновлений» → адрес → «Скачать и установить» → системное подтверждение → установка поверх, данные целы.
3. Прервать загрузку (режим полёта) → снова «Скачать» → докачка продолжается, не с нуля.
4. Подменить байт в APK на сервере → «Контрольная сумма не совпала». Подписать APK другим ключом → «Подпись APK отличается».
5. Указать доверенный ключ и неподписанный манифест → «Подпись манифеста не прошла проверку».
6. После установки — старые APK удалены из `Android/data/ru.qmods.qvk/files/updates`.

## H. Push
1. «Диагностический центр Push» — Google Play services/microG определяются верно; на устройстве с ограничением фона показывается ✗.
2. С Google Play services: режим «auto» — прислать сообщение с другого аккаунта при закрытом QVK; записать задержку.
3. Без GMS / с microG: режим Long Poll/«Фоновая доставка» — сообщения приходят; дублей уведомлений нет при смене режима.
4. Два аккаунта: уведомления для второго аккаунта.
5. «Локальная проверка» — показывает тестовое уведомление с честной подписью.

## I. Энергия и устойчивость
1. 1 час в фоне без музыки: в «Батарея» QVK без аномалий; служба QVK Music не запущена (`adb shell dumpsys activity services ru.qmods.qvk` — нет `Qvk3MusicService`).
2. После паузы музыки 10+ минут служба QVK Music завершилась.
3. Нехватка памяти (`adb shell am send-trim-memory ru.qmods.qvk RUNNING_CRITICAL`) во время игры — без вылета.
4. Поворот экрана во всех новых экранах, большой шрифт, тёмная тема — без вылетов и обрезанных элементов.
